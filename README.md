# Poznámky

Pracovný repozitár pre marketingovú tvorbu: články, príspevky na
sociálne siete, podklady pre grafiku a video, analytické prehľady.

## Kde čo nájdeš

- `pokyny/` – pravidlá a vzory, ktoré platia pre všetku tvorbu
  (tón komunikácie, cieľová skupina, vzorové texty)
- `analyzy/` – prehľady, podľa ktorých vyberáme témy projektov
- `clanky/` – návrhy a hotové články
- `socialne-siete/` – návrhy príspevkov
- `grafika-video/` – zadania pre grafiku a video (nie samotné súbory)

## Pravidlá

- Každá poznámka je samostatný súbor `.md`.
- Názvy súborov: malé písmená, bez diakritiky, spojovníky
  (napr. `jesenna-kampan-clanok-1.md`).
- Žiadne heslá ani prístupové kľúče.
